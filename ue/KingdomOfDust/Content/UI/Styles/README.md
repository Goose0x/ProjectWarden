# UI / Styles

Two material languages. Do not cross them.

| Folder | Screens | Notes |
|--------|---------|-------|
| `Ironstock/` | In-game HUD only | Dark metal, amber readouts, HP green. No cyan glass. |
| `CyanGlass/` | Main Menu and Lobby Versus | Frosted cyan panes, white text, orange on the one commit button. No rivets. |

C++ stand-in colors are `UKodUIStyleLibrary` until these materials exist. Author the materials in the Editor and assign them on the Widget Blueprints. **Do not commit `.uasset` files.**
